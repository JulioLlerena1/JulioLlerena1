## Proyectos 
* Aplicacion para organizar viajes (https://github.com/JulioLlerena1/Proyecto-ED-Grupo-10)
Proyecto universitario, del cual se utiliza conocimientos de Java y AndroidStudio con XML, para desarrollar una aplicacion dedicada a la organizacion de viajes en avion, con la ayuda de un sistema de grafos y algoritmos optimizados para encontrar la mejor ruta de una serie de vuelos. Incluyen el uso de la API de GoogleMaps para un mapa interactivo y gadgets para la comodidad del usuario.

* Paguina web como CV (https://github.com/JulioLlerena1/curriculum)
Pagina web estatica desplegada mediante GitHub utilizada como curriculum u hoja de vida. Utiliza exclusivamente HTML y CSS para el estructurado y modelado de la paguina.
  
* LandingPage de AlmacenlLlerena (https://github.com/JulioLlerena1/landing)
Pagina web estatica desplegada en Vercel utilizada como landing page para promocionar un negocio situado en Babahoyo, Los Rios, especializado en la venta de repuestos de bicicleta y moto. Utiliza HTML y TailWineCSS para el estructurado y modelado de la pagina. Incluye el uso de la API de Google Cloud para la localizacion del local en el mapa y una base de datos para obtener el envio de sugerencias/contactos del formulario incluido.

## Tecnologias

* Java: Es el lenguaje de programación principal utilizado para desarrollar la lógica de negocio de la aplicación, el manejo de los algoritmos de grafos y la interactividad de la interfaz.

* Android Studio: Es el entorno de desarrollo integrado (IDE) oficial para el desarrollo de aplicaciones Android, el cual proporciona las herramientas necesarias para compilar, depurar y diseñar la app.

* XML (Extensible Markup Language): Lenguaje de marcado que se utiliza en Android para diseñar y estructurar la interfaz de usuario (vistas, layouts, botones, etc.) de forma separada a la logica del codigo.

* API de Google Maps: Un servicio que permite integrar los mapas de Google directamente en la aplicacion, habilitando funciones como la visualizacion de rutas, mapas interactivos y marcadores geográficos.

* HTML (HyperText Markup Language): Es el lenguaje de marcado estandar que define la estructura basica y el contenido de la pagina web (textos, secciones, enlaces e imagenes).

* CSS (Cascading Style Sheets): Lenguaje de diseño que se encarga del aspecto visual, los estilos, los colores, las tipografias y la distribucion del contenido (layout) del curriculum.

* GitHub Pages: Servicio de alojamiento de sitios estáticos que permite desplegar y publicar paginas web directamente desde un repositorio de GitHub de forma gratuita.

* Tailwind CSS: Un framework de CSS orientado a utilidades que permite diseñar interfaces de forma rapida y moderna directamente desde las clases del HTML, facilitando la creacion de diseños responsivos.

* API de Google Cloud (Maps/Places): Interfaz de programación que proporciona los servicios de mapas y localizacion para incrustar la ubicacion exacta del negocio fisico en Babahoyo.

* Vercel: Una plataforma en la nube optimizada para el despliegue y alojamiento de aplicaciones web y sitios estaticos, conocida por su rapidez y facilidad de integración con repositorios de codigo.

* Base de Datos (servicios de formularios/backend): Sistema informatico dedicado a almacenar de forma estructurada los datos, en este caso, utilizada para registrar y recopilar las sugerencias y datos de contacto enviados por los clientes a traves del formulario.
